# Counting Bits

- [How to Run](#how-to-run)

## Intuition

The goal is to compute the number of set bits (1s) in the binary representation of every integer from $0$ up to $n$, returning the results as an array of length $n + 1$.

Instead of counting set bits individually for each number, we can use dynamic programming and bit manipulation. For any integer $i$:
- Dividing $i$ by $2$ (equivalent to right-shifting by 1, $i \gg 1$) removes its least significant bit.
- The number of 1s in $i$ is equal to the number of 1s in $i \gg 1$, plus $1$ if the least significant bit of $i$ is $1$ (checked via $i \ \& \ 1$), or $0$ otherwise.

Since $i \gg 1 < i$, the answer for the subproblem $i \gg 1$ will always have been computed already.

## Approach

1. Initialize an array `ans` of size $n + 1$ with all values set to $0$.
2. Iterate through each integer $i$ from $1$ up to $n$.
3. Compute `ans[i]` using the recurrence relation:
   $$\text{ans}[i] = \text{ans}[i \gg 1] + (i \ \& \ 1)$$
4. Return the computed array `ans`.
5. The frontend interface prompts the user for an integer $n$ and prints the resulting list of bit counts.

## Complexity

- Time complexity:

$O(n)$

Each number from $1$ to $n$ is processed in constant time $O(1)$ using bitwise shift and bitwise AND operations.

- Space complexity:

$O(n)$

An array of size $n + 1$ is allocated to store and return the bit counts for all values from $0$ to $n$.

## How to Run

### Installing Python & pip

You must have Python 3.6 or higher installed. `pip` is usually included automatically when you install Python.

- **Windows & macOS:** Download the official installer from [python.org](https://www.python.org/downloads/)
- **Important:** During Windows installation, ensure you check the box that says **Add Python to PATH**.
- **Linux (Debian/Ubuntu):** Run:

```bash
sudo apt install python3 python3-pip
```

Verify Python and pip are installed by running:

```bash
python --version
pip --version
```

### Setup and Execution

Follow these steps to run the project locally in Command Prompt:

Open Command Prompt and

1. **Clone the repository:**

```bash
git clone https://github.com/kishindra-ux/dsa-python.git
```

2. **Navigate to the project directory:**

```bash
cd dsa-python
cd leetcode
```

3. **Run the script:**

Execute the Python file from your terminal:

```bash
python "338._Counting_Bits.py"
```

### Usage Instructions

1. Upon running the script, you will be presented with a main menu to either **Enter the program** (1) or **Exit** (2).
2. If you enter `1`, the program will prompt you to enter the integer $n$.
3. Enter the number for which you want to count set bits up to.
4. The program will compute and display the list of bit counts from $0$ to $n$.
5. Enter `2` to exit the program or `1` to test with another number.

## To Safely Clear the Program in Command Prompt

**Clear the project directory from Command Prompt:**

```bash
cd ..
cd ..
```

Then:

```bash
rmdir /s /q dsa-python
```
