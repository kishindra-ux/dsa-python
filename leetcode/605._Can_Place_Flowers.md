# Can Place Flowers

- [How to Run](#how-to-run)

## Intuition

The goal is to determine if $n$ new flowers can be planted in a flowerbed without violating the rule that no two flowers can be planted in adjacent plots.

A flower can be planted at any plot with value `0` as long as both its left and right neighbors are also empty (or if the plot is at the boundary of the flowerbed). By iterating through the array and greedily planting a flower in every available valid plot as early as possible, we maximize the number of flowers we can plant.

If at any point the remaining count of flowers to plant ($n$) reaches zero or less, we can immediately conclude that it is possible.

## Approach

1. If $n = 0$, return `True` immediately since no flowers need to be planted.
2. Iterate through each plot index `i` of the flowerbed.
3. For each plot, check if `flowerbed[i] == 0`.
4. Determine if the adjacent plots are empty:
   - Left side is empty if `i == 0` or `flowerbed[i - 1] == 0`.
   - Right side is empty if `i == length - 1` or `flowerbed[i + 1] == 0`.
5. If both conditions are satisfied, plant a flower by setting `flowerbed[i] = 1` and decrement $n$ by 1.
6. If $n$ reaches 0 during iteration, return `True`.
7. After scanning all plots, return `True` if $n \le 0$, otherwise return `False`.
8. The frontend interface allows the user to input the flowerbed list and the count of flowers to plant, displaying the resulting boolean value.

## Complexity

- Time complexity:

$O(N)$

Where $N$ is the number of plots in `flowerbed`. The algorithm scans through the array at most once, performing constant-time $O(1)$ checks and updates at each index.

- Space complexity:

$O(1)$

The flowerbed array is modified in-place and only a constant amount of extra memory is used for iteration and boundary checks.

## How to Run

### Installing Python & pip

You must have Python 3.6 or higher installed. `pip` is usually included automatically when you install Python.

- **Windows & macOS:** Download the official installer from [python.org](https://www.python.org/downloads/)
- **Important:** During Windows installation, ensure you check the box that says **Add Python to PATH**.
- **Linux (Debian/Ubuntu):** Run:

```bash
sudo apt install python3 python3-pip
```

Verify Python and pip are installed by running:

```bash
python --version
pip --version
```

### Setup and Execution

Follow these steps to run the project locally in Command Prompt:

Open Command Prompt and

1. **Clone the repository:**

```bash
git clone https://github.com/kishindra-ux/dsa-python.git
```

2. **Navigate to the project directory:**

```bash
cd dsa-python
cd leetcode
```

3. **Run the script:**

Execute the Python file from your terminal:

```bash
python "605._Can_Place_Flowers.py"
```

### Usage Instructions

1. Upon running the script, you will be presented with a main menu to either **Enter the program** (1) or **Exit** (2).
2. If you enter `1`, the program will prompt you to enter the flowerbed list separated by spaces (e.g., `1 0 0 0 1`).
3. Enter the number of flowers ($n$) that need to be planted.
4. The program will evaluate whether $n$ flowers can be placed without violating the adjacent-flower rule.
5. The result (`True` or `False`) will be displayed on the console.
6. Enter `2` to exit the program or `1` to run the check again with different inputs.

## To Safely Clear the Program in Command Prompt

**Clear the project directory from Command Prompt:**

```bash
cd ..
cd ..
```

Then:

```bash
rmdir /s /q dsa-python
```
