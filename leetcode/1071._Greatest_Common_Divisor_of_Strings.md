# Greatest Common Divisor of Strings

* [How to Run](#how-to-run)

## Intuition

The goal is to find the largest string that can be used to repeatedly construct both given strings.

First, the program checks whether the two strings have the same repeating pattern. This is done by comparing `str1 + str2` with `str2 + str1`.

If these two combinations are not equal, there is no common repeating string, so the program returns an empty string.

If they are equal, the greatest common divisor of the lengths of the two strings is calculated using the Euclidean algorithm. The substring from the beginning of `str1` up to this GCD length is then returned as the Greatest Common Divisor of Strings.

## Approach

1. Find the lengths of `str1` and `str2`.
2. Calculate the Greatest Common Divisor of the two lengths using the Euclidean algorithm.
3. Compare `str1 + str2` with `str2 + str1`.
4. If they are different, return an empty string because the strings do not have a common repeating pattern.
5. If they are equal, use the GCD of the two string lengths.
6. Return the substring of `str1` from index `0` to the calculated GCD.
7. The frontend allows the user to enter two strings and displays the resulting Greatest Common Divisor of Strings.

## Complexity

- Time complexity:

\(O(N + M)\)

Where \(N\) is the length of `str1` and \(M\) is the length of `str2`. The string concatenation and comparison operations depend on the total input size, while the Euclidean algorithm takes logarithmic time relative to the input lengths.

- Space complexity:

\(O(N + M)\)

The concatenated strings used for comparison require space proportional to the lengths of the two input strings.

## How to Run

### Installing Python & pip

You must have Python 3.6 or higher installed. `pip` is usually included automatically when you install Python.

* **Windows & macOS:** Download the official installer from [python.org](https://www.python.org/downloads/)
* **Important:** During Windows installation, ensure you check the box that says **Add Python to PATH**.
* **Linux (Debian/Ubuntu):** Run:

```bash
sudo apt install python3 python3-pip
```

Verify Python and pip are installed by running:

```bash
python --version
pip --version
```

### Setup and Execution

Follow these steps to run the project locally in Command Prompt:

Open Command Prompt and

1. **Clone the repository:**

```bash
git clone https://github.com/kishindra26mei10033-boop/dsa-python.git
```

2. **Navigate to the project directory:**

```bash
cd dsa-python
cd leetcode
```

3. **Run the script:**

Execute the Python file from your terminal:

```bash
python "1071._Greatest_Common_Divisor_of_Strings.py"
```

### Usage Instructions

1. Upon running the script, you will be presented with a main menu to either **Enter the program** (1) or **Exit** (2).
2. If you enter `1`, the program will ask you to enter **String 1** and **String 2**.
3. Enter the two strings that you want to check.
4. The program will automatically determine whether the two strings have a common repeating pattern.
5. If a Greatest Common Divisor of Strings exists, the program will display the result.
6. If no common divisor exists, the program will display an empty result.
7. Enter `2` to exit the program or `1` to continue using the program.
