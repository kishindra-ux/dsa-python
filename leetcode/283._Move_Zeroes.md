# Move Zeroes

- [How to Run](#how-to-run)

## Intuition

The goal is to move all zeros present in an array to the end while maintaining the relative order of the non-zero elements, and doing so in-place without making a copy of the array.

We can maintain a pointer/index `count` that tracks the position where the next non-zero element should be placed. As we iterate through the list with index `i`, whenever we encounter a non-zero value, we swap the element at index `count` with the element at index `i`, then increment `count`. 

This effectively pushes all non-zero elements forward in their original order, leaving all zeros at the end.

## Approach

1. Initialize a pointer `count = 0` to track the boundary of non-zero elements.
2. Iterate through the array using index `i` from `0` to the length of the list.
3. Check if the element at index `i` is non-zero (within valid 32-bit integer constraints).
4. If it is non-zero, swap the element at `count` with the element at `i`.
5. Increment `count` by 1.
6. Continue until all elements in the array have been processed.
7. The array is modified in-place, with all zeros shifted to the end.

## Complexity

- Time complexity:

$O(N)$

Where $N$ is the number of elements in `nums`. We traverse the list once using a single loop, performing constant-time $O(1)$ operations and swaps at each step.

- Space complexity:

$O(1)$

The modification is performed directly in-place on the input array without allocating extra auxiliary memory.

## How to Run

### Installing Python & pip

You must have Python 3.6 or higher installed. `pip` is usually included automatically when you install Python.

- **Windows & macOS:** Download the official installer from [python.org](https://www.python.org/downloads/)
- **Important:** During Windows installation, ensure you check the box that says **Add Python to PATH**.
- **Linux (Debian/Ubuntu):** Run:

```bash
sudo apt install python3 python3-pip
```

Verify Python and pip are installed by running:

```bash
python --version
pip --version
```

### Setup and Execution

Follow these steps to run the project locally in Command Prompt:

Open Command Prompt and

1. **Clone the repository:**

```bash
git clone https://github.com/kishindra-ux/dsa-python.git
```

2. **Navigate to the project directory:**

```bash
cd dsa-python
cd leetcode
```

3. **Run the script:**

Execute the Python file from your terminal:

```bash
python "283._Move_Zeroes.py"
```

### Usage Instructions

1. Upon running the script, the predefined input array `nums = [0, 1, 0, 3, 12]` will be passed to `moveZeroes`.
2. The function modifies the list in-place by moving all `0`s to the end while keeping the order of `1`, `3`, and `12`.
3. The modified list `[1, 3, 12, 0, 0]` will be printed directly to the console.
