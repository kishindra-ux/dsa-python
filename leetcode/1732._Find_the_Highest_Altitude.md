# Find the Highest Altitude

- [How to Run](#how-to-run)

## Intuition

A biker starts a road trip at altitude `0`. The input array `gain` represents the net gain in altitude between consecutive points along the route.

To determine the highest altitude reached at any point, we can simulate the trip step by step. We start with a current altitude of `0` and a maximum altitude of `0`. As we add each net gain to our current altitude, we keep track of the highest value encountered.

At the end of the trip, the recorded maximum altitude will be the peak altitude reached.

## Approach

1. Initialize `current_alt = 0` to represent the starting altitude at point 0.
2. Initialize `max_alt = 0` to record the highest altitude reached so far.
3. Iterate through each net altitude gain `i` in the array `gain`.
4. Update `current_alt` by adding `i` to it.
5. Update `max_alt` to be the maximum of `max_alt` and `current_alt`.
6. After processing all gains in the list, return `max_alt`.
7. The frontend interface allows the user to input the list of net gains and displays the resulting highest altitude.

## Complexity

- Time complexity:

$O(N)$

Where $N$ is the length of the array `gain`. We iterate through the list of gains exactly once, performing constant-time $O(1)$ addition and comparison operations at each step.

- Space complexity:

$O(1)$

The algorithm uses only two integer variables (`current_alt` and `max_alt`) to track the values, requiring constant extra memory.

## How to Run

### Installing Python & pip

You must have Python 3.6 or higher installed. `pip` is usually included automatically when you install Python.

- **Windows & macOS:** Download the official installer from [python.org](https://www.python.org/downloads/)
- **Important:** During Windows installation, ensure you check the box that says **Add Python to PATH**.
- **Linux (Debian/Ubuntu):** Run:

```bash
sudo apt install python3 python3-pip
```

Verify Python and pip are installed by running:

```bash
python --version
pip --version
```

### Setup and Execution

Follow these steps to run the project locally in Command Prompt:

Open Command Prompt and

1. **Clone the repository:**

```bash
git clone https://github.com/kishindra-ux/dsa-python.git
```

2. **Navigate to the project directory:**

```bash
cd dsa-python
cd leetcode
```

3. **Run the script:**

Execute the Python file from your terminal:

```bash
python "1732._Find_the_Highest_Altitude.py"
```

### Usage Instructions

1. Upon running the script, you will be presented with a main menu to either **Enter the program** (1) or **Exit** (2).
2. If you enter `1`, the program will prompt you to enter the altitude gains separated by spaces (e.g., `-5 1 5 0 -7`).
3. Enter the list of integer gains.
4. The program will calculate the running altitude and determine the highest altitude reached.
5. The resulting maximum altitude will be displayed on the console.
6. Enter `2` to exit the program or `1` to run the calculation again with a different set of inputs.

## To Safely Clear the Program in Command Prompt

**Clear the project directory from Command Prompt:**

```bash
cd ..
cd ..
```

Then:

```bash
rmdir /s /q dsa-python
```
