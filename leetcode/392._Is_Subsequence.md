# Is Subsequence

* [How to Run](#how-to-run)

## Intuition

A subsequence of a string is a new string formed from the original string by deleting some (can be none) of the characters without disturbing the relative positions of the remaining characters.

To check whether string `s` is a subsequence of string `t`, we can use a two-pointer approach. We traverse both strings simultaneously:
- One pointer `i` tracks characters in `s`.
- Another pointer `j` scans through `t`.

Whenever characters match (`s[i] == t[j]`), we advance the pointer `i` to look for the next character of `s`. We always advance pointer `j` to continue checking `t`.

If pointer `i` reaches the end of `s`, it means all characters of `s` were found in `t` in the correct relative order.

## Approach

1. Initialize two pointers: `i = 0` for string `s`, and `j = 0` for string `t`.

2. Use a `while` loop that continues as long as `i < len(s)` and `j < len(t)`.

3. At each step, compare `s[i]` with `t[j]`:
   - If they match, increment `i` by 1.
   - Increment `j` by 1 regardless of whether there is a match.

4. Once the loop terminates, check if `i == len(s)`.

5. Return `True` if `i == len(s)` (all characters matched in sequence), otherwise return `False`.

6. The frontend interface allows the user to enter the target word (`t`) and the candidate subsequence (`s`), displaying the boolean result.

## Complexity

* Time complexity:

$O(N)$

Where $N$ is the length of string `t`. In the worst-case scenario, the algorithm traverses string `t` at most once, performing constant-time $O(1)$ operations at each character.

* Space complexity:

$O(1)$

The algorithm only maintains two integer pointer indices (`i` and `j`), requiring $O(1)$ constant auxiliary memory.

## How to Run

### Installing Python & pip

You must have Python 3.6 or higher installed. `pip` is usually included automatically when you install Python.

* **Windows & macOS:** Download the official installer from [python.org](https://www.python.org/downloads/)

* **Important:** During Windows installation, ensure you check the box that says **Add Python to PATH**.

* **Linux (Debian/Ubuntu):** Run:

```bash
sudo apt install python3 python3-pip
```

Verify Python and pip are installed by running:

```bash
python --version
pip --version
```

### Setup and Execution

Follow these steps to run the project locally in Command Prompt:

Open Command Prompt and

1. **Clone the repository:**

```bash
git clone https://github.com/kishindra-ux/dsa-python.git
```

2. **Navigate to the project directory:**

```bash
cd dsa-python
cd leetcode
```

3. **Run the script:**

Execute the Python file from your terminal:

```bash
python "392._Is_Subsequence.py"
```

### Usage Instructions

1. Upon running the script, you will be presented with a main menu to either **Enter the program** (1) or **Exit** (2).

2. If you enter `1`, the program will prompt you to enter the main word (`t`) and the candidate subsequence (`s`).

3. Enter both strings when prompted.

4. The program will evaluate whether `s` is a valid subsequence of `t`.

5. The result (`True` or `False`) will be printed to the terminal.

6. Enter `2` to exit the program or `1` to test another pair of strings.

## To Safely Clear the Program in Command Prompt

cd ..
