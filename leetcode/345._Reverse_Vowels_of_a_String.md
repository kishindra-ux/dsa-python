# Reverse Vowels of a String

* [How to Run](#how-to-run)

## Intuition

The goal is to reverse the positions of all vowels in a given string while keeping the consonants and other characters in their original positions.

The program identifies all vowels in the string, including uppercase and lowercase vowels (`a, e, i, o, u, A, E, I, O, U`). It stores their positions and values in separate lists.

After collecting the vowels, the program replaces each vowel position with the vowels taken from the end of the list. This reverses the order of the vowels without changing the positions of other characters.

## Approach

1. Convert the input string into a list of characters so that individual characters can be modified.
2. Define a tuple containing all uppercase and lowercase vowels.
3. Initialize two empty lists:
   - `index` to store the positions of vowels.
   - `value` to store the vowels found in the string.
4. Iterate through the input string and check whether each character is a vowel.
5. If a character is a vowel, store its index in the `index` list and its value in the `value` list.
6. Iterate through the stored vowel positions.
7. Replace each vowel position in the character list with the last vowel removed from the `value` list using `pop()`.
8. Join the character list into a string using `"".join(list_s)`.
9. Return the final string with its vowels reversed.

## Complexity

- **Time complexity:**

\(O(N)\)

Where \(N\) is the length of the input string. The program traverses the string to identify vowels, traverses the vowel positions to replace them, and joins the characters into the final string. Each operation takes linear time in the worst case.

- **Space complexity:**

\(O(N)\)

The program stores the input characters in a list and maintains separate lists for vowel positions and vowel values. In the worst case, these lists require space proportional to the length of the input string.

## How to Run

### Installing Python & pip

You must have Python 3.6 or higher installed. `pip` is usually included automatically when you install Python.

* **Windows & macOS:** Download the official installer from [python.org](https://www.python.org/downloads/).
* **Important:** During Windows installation, ensure you check the box that says **Add Python to PATH**.
* **Linux (Debian/Ubuntu):** Run:

```bash
sudo apt install python3 python3-pip
```

Verify Python and pip are installed by running:

```bash
python --version
pip --version
```

### Setup and Execution

Follow these steps to run the project locally in Command Prompt.

Open Command Prompt and:

1. **Clone the repository:**

```bash
git clone https://github.com/kishindra26mei10033-boop/dsa-python.git
```

2. **Navigate to the project directory:**

```bash
cd dsa-python
cd leetcode
```

3. **Run the script:**

Execute the Python file from your terminal:

```bash
python "345._Reverse_Vowels_of_a_String.py"
```

### Usage Instructions

1. Upon running the script, you will be presented with a main menu offering two options: **Enter the program (1)** or **Exit (2)**.
2. Enter `1` to start the program.
3. Enter the string whose vowels you want to reverse.
4. The program checks whether the input string length is within the specified range of 1 to \(3 \times 10^5\) characters.
5. If the input is valid, the program reverses the order of the vowels while preserving the positions of consonants and other characters.
6. The program displays the resulting string.
7. Enter `1` to process another string or `2` to exit the program.
